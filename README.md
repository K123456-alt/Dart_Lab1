Консольное приложение на языке Dart, которое принимает список оценок студентов и выводит статистику: средний балл, максимальную и минимальную оценку, а также итоговую текстовую оценку для каждого студента.

# Ответы на вопросы

1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Python типизация динамическая: тип переменной определяется во время выполнения, и переменная может менять тип в любой момент. В Dart типизация статическая: тип переменной известен на этапе компиляции и не может быть изменён после присвоения.

Практическое преимущество: компилятор ловит целый класс ошибок ещё до запуска программы. Например, попытка присвоить строку в переменную типа int или вызвать метод на null без проверки — это ошибка компиляции, а не падение в рантайме. Это ускоряет разработку и делает код надёжнее.

2. Что означает String?? Чем отличается от String?
String — это тип, который гарантированно не может содержать null. Компилятор не позволит присвоить null такой переменной.
String? — это nullable-тип, который может содержать либо строку, либо null. Перед вызовом методов на такой переменной нужно либо проверить её через if (x != null), либо использовать оператор ?., либо утверждать через !, что там точно не null.

3. Зачем в Dart final, если в Python можно просто договориться не менять
переменную?
final — это не «договорённость», а гарантия на уровне компилятора. Если переменная объявлена как final, попытка присвоить ей новое значение вызовет ошибку компиляции. В Python такой механизм отсутствует: программист может только договориться с собой, но ничто не помешает случайно изменить значение. final делает намерение явным и защищает от ошибок.

4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
Позиционный параметр передаётся по порядку, без указания имени. Именованный параметр заключается в фигурные скобки {} и передаётся с указанием имени. required означает, что параметр обязателен.
## Пример:
void describePet({required String name, String species = 'kot', int age = 0}) {
  print('$name - $species, возраст $age');
}

void main() {
  // Именованный вызов
  describePet(name: 'Барсик', age: 3);
  describePet(name: 'Шарик', species: 'пёс');
}
